# 倒数日 · 黄历 · 每日一句

一款纯本地化的微信小程序工具：黄历查询、倒数日记录、每日一句、历史上的今天。**零服务器、零后端、零第三方接口**，所有数据本地计算与存储，个人主体即可过审上线。

## 功能

### 今日页
- 📅 公历 / 农历 / 干支 / 生肖 / 星座
- 🧧 传统黄历宜忌（简化算法，仅供生活参考）
- 🎉 节日与二十四节气自动识别（春节、除夕、中秋、冬至等）
- 💬 每日一句（100 条内置语料，支持「换一句」随机切换）
- 📜 历史上的今天（81 天内置史实，自动补全年月日格式）
- ⏰ 倒数日到期横幅提醒
- 下拉刷新 / 微信分享

### 倒数日页
- ➕ 添加 / 点击编辑 / 长按删除
- 🔁 每年重复（生日、纪念日自动滚动到下一年）
- 📌 置顶、5 种主题色自定义
- 🔥 7 天内到期自动「临近」高亮
- 💾 数据备份 / 恢复（剪贴板导入导出，无需账号与服务器）

## 技术特点

- **纯前端架构**：无任何网络请求，不需要域名备案、HTTPS 接口、服务器运维
- **本地农历算法**：`utils/lunar.js` 内置 1900–2100 年农历数据表，本地计算农历、干支、生肖、二十四节气、宜忌
- **本地存储**：倒数日数据使用 `wx.setStorageSync` 存于用户设备
- **内置语料**：每日一句（100 条）与历史上的今天（81 天）均打包进代码包，可自由扩充

## 目录结构

```
├── app.js / app.json / app.wxss    # 全局逻辑与配置
├── sitemap.json
├── pages/
│   ├── today/                      # 今日页（黄历 + 每日一句 + 历史上的今天）
│   └── days/                       # 倒数日页
└── utils/
    ├── lunar.js                    # 农历/干支/生肖/节气/宜忌算法库
    ├── quotes.js                   # 每日一句语料库
    └── history.js                  # 历史上的今天数据集
```

## 运行方式

1. 克隆本仓库
2. 打开**微信开发者工具** → 导入项目 → 选择本目录
3. AppID 可先用「测试号」，正式发布前在 `project.config.json` 中替换为你自己的 AppID
4. 点击「编译」即可预览

## 自定义扩充

- 加句子：编辑 `utils/quotes.js`，追加 `{ text: '句子', from: '出处' }`
- 加历史事件：编辑 `utils/history.js`，格式 `'月-日': ['1936年 某事件']`（页面会自动补全为年月日）
- 改主题色：全局搜索 `#B03A2E`（朱红）替换为你喜欢的颜色
